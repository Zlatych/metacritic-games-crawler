# Metacritic Games Crawler

Сервис раз в час обрабатывает 20 новых игр с [Metacritic](https://www.metacritic.com/game/), сохраняет их в БД, делает краткие резюме отзывов критиков и игроков, подбирает похожие игры, находит самый популярный летсплей на YouTube и пишет по нему вывод. Есть веб-интерфейс с каталогом и карточками игр, а также мониторинг в реальном времени.

Всё работает локально и на бесплатных ресурсах. Платных API и Docker нет, база — SQLite-файл.

## Быстрый старт

Требования: **Node.js ≥ 22** (проверено на 24), ffmpeg в `PATH` (нужен только для STT-фолбэка, см. ниже).

```bash
npm install
npm run setup      # скачивает yt-dlp в ./bin, ставит Chromium для Playwright, создаёт .env
# в .env вписать LLM_API_KEY (бесплатный ключ Groq: https://console.groq.com/keys)
npm start          # http://localhost:3000
```

Первая обработка запускается сразу при старте, дальше — по cron `0 * * * *`.
Без `LLM_API_KEY` сервис тоже работает: резюме строятся экстрактивным алгоритмом, а вывод по летсплею — это фрагмент транскрипта.

| Команда | Что делает |
| --- | --- |
| `npm run dev` | запуск с hot reload |
| `npm run typecheck` | проверка типов (`tsc --noEmit`) |
| `npm run test:e2e` | e2e-тесты UI на Playwright (отдельная БД `tmp/e2e.db`) |
| `npm run db:generate` | генерация SQL-миграции после изменения `src/db/schema.ts` |
| `npm run export-chats` | копирует JSONL-транскрипты чата с ИИ в `./chats` |

## Стек

| Задача | Решение | Почему |
| --- | --- | --- |
| Язык / рантайм | TypeScript, Node 24, `tsx` | без отдельного шага сборки |
| Веб | [Hono](https://hono.dev) + JSX SSR + [HTMX](https://htmx.org) | лёгкий сервер; фильтры, поиск и бесконечная прокрутка без SPA-фреймворка |
| Мониторинг | Server-Sent Events | односторонний поток «сервер → браузер», проще WebSocket |
| БД | SQLite (better-sqlite3, WAL) + [Drizzle ORM](https://orm.drizzle.team) | один файл, типизированные запросы, миграции через drizzle-kit |
| Планировщик | [croner](https://github.com/hexagon/croner) с `protect: true` | запуски не накладываются друг на друга |
| Валидация | zod | конфиг из env и ответы внешних API проверяются по схемам |
| LLM | любой OpenAI-совместимый API, по умолчанию **Groq free tier** (`llama-3.1-8b-instant`) | бесплатно и быстро; Gemini и OpenRouter переключаются через `.env` |
| Распознавание речи | Groq Whisper (`whisper-large-v3-turbo`) | тот же бесплатный ключ |
| YouTube | [yt-dlp](https://github.com/yt-dlp/yt-dlp) | поиск, субтитры и аудио без YouTube API-ключа |
| Браузер | Playwright | фолбэк для Metacritic, если он блокирует прямые запросы, и e2e-тесты |

## Как это устроено

```
cron / кнопка ─► selection ─► [scraper ×3] ─► [summarizer ×1] ─┐
                                    │                           ├─► similarity ─► готово
                                    └────────► [letsplay ×1] ───┘
                     все воркеры отчитываются в monitor ─► SSE ─► /monitor
```

### Источник данных

Сайт Metacritic построен на Nuxt и берёт данные из публичного JSON API `backend.metacritic.com`. Сервис обращается к тем же эндпоинтам, что и сайт (`src/metacritic/api.ts`). Это быстрее и надёжнее парсинга HTML, ключ не нужен. Если API начнёт отвечать 403 или 429, `http.ts` в режиме `MC_FETCH_MODE=auto` переключается на запросы из настоящего Chromium через Playwright, с куками сайта.

С каждой игры собираются: название, обложка, описание, разработчик, издатель, жанры, дата, возрастной рейтинг, видео (трейлер), Metascore и Userscore **по каждой платформе** и отзывы. Отзывы берутся с трёх платформ, где их больше всего.
Userscore со статусом «tbd» (слишком мало оценок) сохраняется как `null`, а не 0.

### Выбор 20 игр на запуск (`src/pipeline/selection.ts`)

- В таблице `processed_games` хранятся игры, обработанные **сегодня**. В `daily_progress` хранится курсор дня: пройдены ли уже New Releases и какая страница «See All» следующая.
- Первый запуск дня берёт карусель **New Releases** со страницы `/game/`.
- Следующие запуски листают `/browse/game/all/all/all-time/new/` страница за страницей и пропускают игры, обработанные сегодня.
- Курсор сдвигается, только когда страница выбрана целиком. Поэтому порядок не сбивается, даже если на странице больше игр, чем помещается в один запуск.
- С новым днём курсор начинается заново. Игра, которая уже есть в БД, **обновляется** (upsert).

### Резюме отзывов (`src/ai/reviews.ts`)

- Отдельно для критиков и для игроков. Формат: короткое резюме, что нравится, что не нравится.
- В промпт попадает сбалансированная выборка из негативных, позитивных и смешанных отзывов в пределах лимита символов.
- Резюме **перегенерируется только при изменении набора отзывов**: хранится sha256 от набора. Так экономятся бесплатные лимиты LLM.
- Если LLM недоступна, работает экстрактивный фолбэк. Такое резюме будет перегенерировано, когда LLM снова станет доступна.

### Похожие игры (`src/pipeline/similarity.ts`)

Похожие игры подбираются по контенту среди игр, уже лежащих в БД. После каждого запуска оценки пересчитываются по формуле:
`0.55 · cos(TF-IDF описаний) + 0.35 · Jaccard(жанры) + 0.1 · тот же разработчик`.
Сохраняются до 6 лучших совпадений с оценкой ≥ 0.12. На карточке игры они показаны кликабельным списком.

### Летсплей (`src/youtube/letsplay.ts`)

1. Поиск `ytsearch25:<игра> let's play` через yt-dlp. Отсеиваются:
   - трансляции, которые идут сейчас;
   - видео короче 8 минут;
   - обзоры, трейлеры, гайды и видео «no commentary» (в летсплее важна речь блогера);
   - видео, в названии которых нет названия игры **целой фразой**. Например, для «Alice Nation» не подойдёт «…Education for the Nation».
2. Среди оставшихся предпочтение отдаётся явным let's play / walkthrough / part N. Выбирается видео с максимумом просмотров.
3. Транскрипт:
   - Сначала **оригинальные** субтитры: ручные или автоматические `<lang>-orig`. Скачивается ровно одна дорожка, потому что автопереводы YouTube отвечают 429.
   - Если субтитров нет — Whisper по первым `STT_MAX_MINUTES` минутам аудио.
4. LLM пишет вывод на русском: суть, плюсы и минусы глазами блогера, вердикт. Для длинных видео в промпт идут 6 равномерно распределённых фрагментов транскрипта.

Удачный летсплей обновляется раз в 7 дней. Если видео не нашлось, повторная попытка будет через 6 часов. Игры, добавленные раньше, догружаются бэкфиллом.

### Мониторинг (`/monitor`)

Страница мониторинга показывает в реальном времени через SSE:
- текущий запуск: этап и прогресс;
- пулы воркеров и состояние каждого воркера (idle / busy, задача, последняя ошибка);
- счётчики обработанных и упавших задач;
- историю запусков и журнал событий.

Кнопка «Запустить обработку» вызывает `POST /api/run`. Если запуск уже идёт, ответ будет `409`.

### Веб-интерфейс

- `/` — каталог: поиск по названию, фильтр по платформе, сортировка по Metascore, Userscore, дате или названию, бесконечная прокрутка. При фильтре по платформе сортировка идёт по оценкам **этой** платформы.
- `/game/:slug` — карточка игры:
  - оценки по платформам и трейлер;
  - резюме отзывов критиков и игроков;
  - летсплей: видео, вывод и транскрипт;
  - похожие игры.
- JSON API:
  - `/api/games?q=&platform=&sort=`
  - `/api/games/:slug`
  - `/api/platforms`
  - `/api/monitor`
  - `/api/monitor/stream`

## Настройки (`.env`)

Полный список с комментариями — в [.env.example](.env.example). Основные:

| Переменная | По умолчанию | |
| --- | --- | --- |
| `LLM_API_KEY` / `LLM_BASE_URL` / `LLM_MODEL` | Groq, `llama-3.1-8b-instant` | любой OpenAI-совместимый провайдер |

| `GAMES_PER_RUN` | `20` | |
| `MC_FETCH_MODE` | `auto` | `http` / `browser` / `auto` |
| `LETSPLAY_ENABLED` | `true` | |

## Замечания

- Если в системе задан `HTTP(S)_PROXY`, yt-dlp ходит через него, а Node `fetch` к Metacritic — напрямую. Для `curl` к localhost нужен `--noproxy '*'`.
- Тесты: только e2e smoke-тесты ключевых сценариев UI (`tests/ui.spec.ts`) на заранее заполненной БД. Основное внимание уделено рабочему функционалу.
- Чат с ИИ, в котором писался проект, — в папке [`chats/`](chats/) (сырые JSONL-транскрипты Claude Code). При экспорте маскируются почты, IP-адреса (кроме loopback), API-ключи и токены, ID аккаунта, имя пользователя ОС и хоста. Дополнительные строки для маскировки задаются через `MASK_TERMS="a,b"`.
